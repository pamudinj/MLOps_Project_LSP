# PathMNIST MLOps

Welcome to the documentation for the PathMNIST MLOps project.

## Project Overview

This project implements an end-to-end MLOps pipeline for image classification on the PathMNIST dataset.

Main features include:

- PyTorch Lightning model training
- Hydra configuration management
- Weights & Biases experiment tracking
- Hyperparameter sweeps on Vertex AI
- DVC data versioning
- ONNX model export
- FastAPI inference service
- Docker containerization
- Deployment on Google Cloud Run
- Continuous Integration using GitHub Actions
